Khởi động và chạy trong vài giây.

Hướng dẫn Khởi động Nhanh

~ $ gem install bundler jekyll

~ $ jekyll new my-awesome-site

~ $ cd my-awesome-site

~/my-awesome-site $ bundle exec jekyll serve

# => Bây giờ hãy truy cập http://localhost:4000

Mệt mỏi với các công ty lưu trữ? GitHub Pages được hỗ trợ bởi Jekyll, vì vậy bạn có thể dễ dàng triển khai trang web của mình bằng GitHub miễn phí—kể cả tên miền tùy chỉnh.
